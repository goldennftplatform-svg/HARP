Create songs locally

Song Forge generates full AI songs on your machine via Maestro/Pinokio. Pick an installed engine, write a prompt (and lyrics for vocals if the model supports it), set duration, and hit Create.

Quick sketch (in “More tools”) makes instant 4-stem instrumental sketches with no AI model.
